# Code of conduct

Be kind and assume good faith. Harassment, personal attacks and discrimination aren't welcome here, in any project space.

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). To report a problem, contact the maintainer through their [GitHub profile](https://github.com/Vedthakar). Reports are kept private.
